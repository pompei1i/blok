# Changelog

## [0.9.16] — 2026-06-12

### Added
- **Экономика и гача** — за выполнение ежедневных квестов теперь начисляются **монеты** (🪙, глобальный кошелёк) вдобавок к XP. Магазин с тремя секциями:
  - **Box** — лутбокс за 🪙100: случайная косметика по весам редкостей, **pity** (гарантированный Epic+ на 10-м открытии без него), дубликаты превращаются в **пыль** (✦)
  - **Shop** — детерминированная покупка конкретного предмета за монеты или пыль
  - **Inventory** — владение по слотам с экипировкой/снятием в один клик
- **Косметика профиля (4 типа)** — выпадает из бокса и продаётся в магазине:
  - **Nameplate** — цвет/градиент ника (виден в чате, списке участников, UserBar), легендарный — с анимацией shimmer
  - **Avatar frame** — цветное кольцо/свечение вокруг аватара (везде, где есть аватар)
  - **Badge** — коллекционные emoji-бейджи в карточке профиля (до 3 одновременно)
  - **Banner** — градиентная шапка карточки профиля (наконец задействует поле `banner_url`)
- Косметика **видна другим игрокам вживую** — экипировка денормализуется в `profiles.cosmetics` и долетает через существующую Realtime-подписку на `profiles`, без новых джойнов
- **Быстрый доступ из нижней панели** — иконки 📜 квестов и 🛍 магазина рядом с настройками открывают их модалками (плюс вкладка `store` в правом сайдбаре). Баланс 🪙/✦ показывается в UserBar под уровнем и кликабелен
- **Всплывающие уведомления (тосты)** — при выполнении квеста (прогресс достигает цели) в правом нижнем углу появляется тост «Квест выполнен!» с наградой; авто-скрытие через 5 сек
- **Полная локализация** экономики, магазина и квест-тостов на 6 языков (EN/RU/UK/PL/DE/ES)

### Fixed
- **XP теперь обновляется в реальном времени** — не было Realtime-подписки на `server_members`, поэтому XP/уровень менялись только после перезагрузки. Добавлена подписка `public:server_members`
- **Прогресс ежедневных квестов в реальном времени** — таблицы `daily_quest_progress` и `server_members` не были в публикации `supabase_realtime`, события не приходили; добавлены в публикацию

### Security / Anti-abuse
- Весь RNG и списание валюты — **только на сервере** в `SECURITY DEFINER` RPC; клиент не может подделать бросок или баланс (`FOR UPDATE` на строке кошелька)
- **Глобальный дневной кап** заработка монет (`daily_coin_earn`, PK без `server_id`) — защита от фарма через создание своих серверов, т.к. квесты per-server, а кошелёк глобальный
- Все новые таблицы под RLS: клиентам только `SELECT own` / `SELECT active`, мутации — исключительно через RPC

### Database
- `user_wallet` (coins + dust), `item_catalog`, `user_inventory`, `user_gacha_state` (pity), `daily_coin_earn` (глобальный кап)
- Колонки на `profiles`: `equipped_nameplate/avatar_frame/banner`, `equipped_badges`, `cosmetics` (jsonb-снапшот)
- RPC: `claim_quest_reward`, `open_loot_box`, `buy_item`, `equip_item`, `unequip_slot`, `rebuild_cosmetics` (миграция `20260611_economy.sql`)
- Realtime-публикация: `user_wallet`, `daily_quest_progress`, `server_members` (миграции `20260611_economy.sql` + `20260611_realtime_progress.sql`)

> ⚠️ Миграции `supabase/migrations/20260611_economy.sql` и `20260611_realtime_progress.sql` нужно применить к проекту Supabase (не накатываются автоматически).

## [0.9.15] — 2026-06-10

### Fixed
- **Демонстрация экрана: чёрный экран у поздно подключившихся** — при статичной картинке нативный захват дедуплицирует одинаковые кадры, поэтому новый зритель не получал ничего до следующего изменения экрана. Теперь последний кадр кешируется и отправляется зрителю сразу при открытии канала
- **Демонстрация экрана: срыв картинки при входе нового участника** — `screenshare_start` теперь идемпотентен: уже подключённые зрители не пересоздают соединение, когда в канал заходит третий участник
- **Демонстрация экрана: накопление и перестановка кадров у зрителя** — декодирование переведено на `createImageBitmap` с коалесингом (newest-wins, одно декодирование за раз) вместо `Blob`+`Image`+`createObjectURL` на каждый кадр; меньше нагрузка на GC, нет рассинхрона кадров
- **Демонстрация экрана: утечка слушателя `tauri://move`** при быстром старте/остановке шеринга
- **Демонстрация экрана: кнопка браузера «Stop sharing»** теперь корректно завершает шеринг и сбрасывает состояние `isScreenSharing`
- **Realtime сообщений мог не работать** — очистка старых каналов выполнялась после создания новых подписок и убивала их; теперь cleanup идёт строго перед `initMessageRealtime`/`initPollRealtime`
- **Push-to-talk перехватывал пробел при наборе текста** — пробел в поле ввода больше не переключает микрофон
- **Утечка realtime-канала DM** при повторном входе (re-login) и канала `profile-self-*` при выходе
- **Кик/назначение роли не работали для только что приглашённого участника** — локальный member создавался с синтетическим id вместо id из БД
- **Логин: фиксированная задержка 500 мс** заменена на опрос профиля с backoff — типичный вход быстрее

## [0.9.14] — 2026-06-08

### Added
- **XP + Levels** — каждое сообщение даёт +5 XP. Уровни 1–10+ с цветовыми тирами (серый → синий → фиолетовый → золотой). Значок уровня рядом с ником в списке участников; прогресс-бар в карточке профиля и UserBar
- **Rich Presence** — кнопка `+ set activity` в UserBar открывает пикер с 6 пресетами (Gaming, Listening, Studying, Working, Watching, AFK). Активность синхронизируется в реальном времени и видна рядом с ником
- **Daily Quests** — новая вкладка «quests» в правом сайдбаре. 3 ежедневных квеста: Send 5 messages (+50 XP), Send 15 messages (+100 XP), React to 5 messages (+75 XP). Прогресс считается автоматически через DB-триггеры; кнопка «Claim XP» атомарно начисляет награду
- **Редизайн карточки профиля** — новый лейаут с level badge на аватарке,presence pill, XP progress bar под именем, кнопки Message и Call для чужих профилей
- **Friends list: Online/Offline секции** — друзья разбиты на Online/Offline с возможностью свернуть. Контекстное меню (ПКМ) с View Profile, Message, Call, Invite to Server, Remove Friend
- **Отключён системный контекст-меню** — ПКМ в пустых местах больше не открывает браузерное меню Chromium

### Fixed
- Карточка профиля показывала "Online" из поля `statusMessage` вместо реального presence-статуса

### Database
- `server_members.xp INTEGER DEFAULT 0` + триггер `trg_message_xp` (+5 XP на каждое сообщение)
- `user_presence.activity TEXT` для rich presence
- Таблицы `daily_quest_progress`, `daily_quest_claims` + триггеры и RPC `claim_quest_xp`
