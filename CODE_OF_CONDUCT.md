# Code of Conduct

## The short version

Be decent. Argue about code, not about people. Assume the person on the other end is
trying to make the project better, and that they may be doing it in their third language.

## The longer version

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Expected:**

- Give feedback on the work, with a reason attached. "This breaks X when Y" is useful;
  "this is bad" is not.
- Accept feedback the same way. Someone finding a flaw in your patch is doing you a favour.
- Respect that people have different levels of experience, hardware, bandwidth, and time.
- Keep discussion in the open where it belongs, so others can learn from it.

**Not acceptable:**

- Harassment, insults, or personal attacks — including in issue titles, commit messages,
  and code comments
- Sexualised language or imagery; unwelcome attention of any kind
- Publishing someone's private information
- Sustained disruption: derailing threads, reopening settled decisions to wear people down
- Discrimination based on who someone is rather than what they wrote

## Scope

This applies everywhere the project lives: issues, pull requests, discussions, commit
history, and any space where you're representing blok.

## Enforcement

Report a problem privately to the maintainer via a
[private security advisory](https://github.com/pompei1i/blok/security/advisories/new)
(it is the only private channel this repository has) or by direct message to
[@pompei1i](https://github.com/pompei1i) on GitHub. Reports are handled confidentially.

Responses scale with the behaviour: a private word, a public correction, a temporary
block, or a permanent ban from the project. The maintainer makes the call, and won't
explain a ban in detail if doing so would expose the reporter.
