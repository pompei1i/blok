# $blok

Discord/Slack-style messenger — **native desktop** app built with Tauri 2.

## Stack

| Layer | Desktop (`desktop/`) |
|---|---|
| UI | React 19, Tailwind CSS 4, Lucide React |
| Language | TypeScript strict |
| Build | Vite 7 (port 1420) |
| State | Zustand 4 |
| Backend | Supabase (Auth, Realtime, PostgreSQL) |
| Desktop | Tauri 2 (NSIS installer, Windows) |
| Audio | cpal (Rust native engine) |
| i18n | 6 languages, 165+ keys (JSON) |

## Architecture

```
blok/
├── app/                     # Next.js App Router (web)
│   ├── layout.tsx
│   └── page.tsx
├── components/blok/         # React components (web)
├── lib/
│   ├── store/               # Zustand stores (auth, group, friends, dm, ui-settings)
│   ├── voice-engine.ts      # WebRTC voice (web)
│   ├── supabaseClient.ts    # Supabase client (NEXT_PUBLIC_*)
│   └── utils.ts
├── hooks/                   # use-mobile etc.
├── styles/                  # Tailwind + terminal theme
└── desktop/                 # Tauri 2 desktop app
    ├── src/
    │   ├── components/blok/
    │   ├── lib/
    │   │   ├── native-voice-engine.ts   # cpal (Rust ↔ TS IPC)
    │   │   ├── voice-engine.ts          # WebRTC fallback
    │   │   └── store/
    │   └── App.tsx
    └── src-tauri/           # Rust backend (audio, tray, updater)
```

## Features

### Auth & Profile
- Sign up and sign in via Supabase Auth
- Profile editing: display name, username, email, status, bio, pronouns, accent color
- Presence: automatically `online` on login, `offline` on exit

### Servers & Channels
- Load servers, channels, categories and members from Supabase
- Create servers, text and voice channels
- Invite users by username or invite code (8 chars, CSPRNG, generated by owner)
- Delete channel with confirmation dialog
- **Roles & permissions** — bitfield role system; owner-only `RoleManagerModal`: create/edit/delete roles with name, color, permissions; assign roles to members

### Text Chat
- Send and receive messages in real time (Supabase Realtime)
- Attachments: images, video, audio, documents (Supabase Storage, up to 10 MB) + drag-and-drop
- GIF picker (Tenor API), emoji picker, mention picker (`@username`)
- Reply system with quote preview
- Edit and delete messages
- Pinned messages (pin bar, jump-to)
- Emoji reactions: realtime + DB
- Message history pagination: load 30 at a time when scrolling to top, position preserved
- Markdown-like formatting + XSS protection (DOMPurify)
- Offline banner on connection loss
- **In-channel search** (`Ctrl+F` / 🔍): debounced ILIKE query, ↑↓ navigation, jump-to-message
- **Polls**: single/multi-choice, anonymous/open, vote confirmation, realtime counters, progress bars
- **Announcements**: red left border + badge; always fires desktop notification to all server members
- Right-click context menu: portal-based, `position: fixed`, never clipped

### Voice Channels
- **Desktop**: native audio engine powered by cpal (Rust) via Tauri IPC
- **Browser**: WebRTC (getUserMedia + RTCPeerConnection + Supabase Realtime signaling)
- Mute / deafen with per-participant icons
- Real-time speaking indicator
- Presence tracking via Supabase Realtime
- Settings: noise suppression, echo cancellation, input volume, push-to-talk
- **Per-user volume** (0–200%) and **local mute** via right-click context menu on any participant
- Screen share (desktop: native GDI picker; browser: getDisplayMedia)
- Screen share quality settings: FPS (1–30), resolution (720p/1080p/1440p/native), JPEG quality

### Presence
- Status dot on avatars: green (online), yellow (afk), red (offline/dnd)
- DB-based heartbeat every 30 s
- "Last seen X ago" for offline friends
- Current user always shown as online

### Friends & DMs
- Friend system: requests, accept/decline, presence statuses
- Floating DM popups with drag, minimize, unread counter
- DM history with attachments and GIFs

### Settings (7 tabs)
| Section | Details |
|---|---|
| Audio: noise suppression / echo cancellation | getUserMedia constraints |
| Audio: input volume (0–100%) | GainNode |
| Audio: push-to-talk (Space) | keydown/keyup |
| Video: camera quality | getUserMedia constraints |
| Video: screen share FPS / resolution / quality | Rust encoder + ui-settings-store |
| View: compact mode, member list toggle, UI scale | CSS variables |
| Theme: dark / light / darker, Custom CSS | CSS variables + live inject |
| Language | 6 languages (EN/RU/UA/PL/DE/ES) |

### Security
- RLS policies on all Supabase tables
- XSS protection: HTML escaping + DOMPurify allowlist
- CSP in `tauri.conf.json` (no `unsafe-inline`/`unsafe-eval`)
- Incoming screen frames clamped to 3840×2160 and 400 KB (canvas DoS protection)
- Invite codes generated with `crypto.getRandomValues` (CSPRNG, 40 bits)

## Running

### Desktop app (Tauri)

```bash
cd desktop
npm install
npm run tauri dev    # dev window
npm run tauri build  # build .exe (NSIS)
```

Or via the build script (installs Rust automatically if missing):
```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Environment variables (`desktop/.env.local`):
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
VITE_TENOR_API_KEY=...        # optional — GIF search
VITE_BAIT_DEFAULT_KEY=...     # Anthropic API key for b.ai.t
```

### Web app (Next.js)

```bash
# from repo root
npm install
npm run dev        # http://localhost:3000
npm run build
npm start
```

Environment variables (`.env.local`):
```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

## Database

| Table | Purpose |
|---|---|
| `profiles` | User profiles |
| `servers` | Servers |
| `channels` | Channels (text / voice) |
| `categories` | Channel categories |
| `server_members` | Server membership + role assignment |
| `roles` | Per-server roles with bitfield permissions |
| `messages` | Channel messages |
| `attachments` | Message attachments |
| `message_reactions` | Emoji reactions |
| `user_relationships` | Friends / requests |
| `dm_channels` | DM channels |
| `dm_messages` | DM messages |
| `user_presence` | Presence heartbeat (`online_at`) |
| `polls` | Polls (question, type, anonymity) |
| `poll_options` | Poll answer options |
| `poll_votes` | Votes (`UNIQUE(poll_option_id, user_id)`) |

`servers.invite_code` — nullable VARCHAR, generated on demand by the owner.

RLS schema — `supabase/policies.sql`. For Realtime:
```sql
ALTER TABLE user_relationships REPLICA IDENTITY FULL;
ALTER TABLE user_presence REPLICA IDENTITY FULL;
```
