# Blok — полный обзор проекта

## Коротко

Blok — это нативная десктопная платформа для общения, похожая на Discord, но с акцентом на собственную кастомизацию, встроенный ИИ, голосовые каналы и игровые механики внутри чата. Проект строится как “мессенджер + community platform + мини-игра внутри общения”.

Сейчас это уже рабочий публичный beta-проект, ориентированный на десктоп, с акцентом на голос, видео, демонстрацию экрана и AI-ассистента.

---

## Что это такое

Blok — это:

- мессенджер для сообществ и друзей;
- десктопное приложение с нативной интеграцией в систему;
- платформа для серверов, каналов, ролей и модерации;
- пространство для голосовых и видеоконференций;
- чат-среда с встроенным ИИ, который может помогать в общении и администрировании;
- “чат с экономикой и прогрессом”, где есть XP, уровни, квесты, лутбоксы и косметика.

То есть Blok — не просто чат, а скорее “командный/сообщественный слой общения с игровыми механиками и ИИ”.

---

## Для чего это нужно

Проект создавался как более гибкая и персонализированная альтернатива привычным коммуникационным платформам. Его главная идея:

- дать людям собственное пространство для сообществ;
- сделать общение более живым за счёт голоса, видео и экрана;
- встроить помощника, который облегчает модерацию и взаимодействие;
- добавить игровые элементы, чтобы общение становилось более вовлекающим.

Идея в том, чтобы объединить:

- текстовый чат;
- голос и видео;
- серверную структуру;
- AI-ассистента;
- экономику и прогресс.

---

## Для кого это

Blok в первую очередь ориентирован на:

- сообщества и гильдии;
- игровые клубы и Discord-like объединения;
- небольшие и средние чаты с активной модерацией;
- пользователей, которым важны голосовые комнаты и экран-шаринг;
- тех, кто хочет более “собственного” и кастомизируемого пространства, чем у крупных централизованных платформ;
- тех, кто хочет экспериментировать с AI внутри чата.

Подходит как для личных чатов и дружеских серверов, так и для более организованных сообществ.

---

## Что уже реализовано

### 1. Основы мессенджера

- текстовые сообщения;
- replies;
- pinned messages;
- emoji reactions;
- edit/delete сообщений;
- вложения и drag-and-drop;
- GIFs;
- announcements;
- поиск по сообщениям;
- быстрый переключатель каналов/серверов.

### 2. Серверы и сообщества

- серверы;
- каналы и категории;
- роли и права доступа;
- moderation tools: bans, timeouts, slow mode, audit log;
- invite codes;
- приветственные/организационные элементы.

### 3. Голос, видео и экран-шаринг

- низкоуровневая голосовая связь;
- шумоподавление и echo cancellation;
- push-to-talk;
- локальное mute/деafen;
- управление громкостью каждого пользователя;
- video calls;
- screen share;
- экспериментальный режим для некоторых сценариев.

### 4. AI-ассистент b.ai.t

- встроенный AI-помощник;
- запуск прямо из чата;
- создание опросов;
- суммаризация каналов;
- перевод сообщений;
- контекстная помощь в рамках сервера;
- AI работает через серверный proxy, без раскрытия ключа в клиенте.

### 5. Игровая экономика внутри чата

- XP и уровни;
- ежедневные квесты;
- loot boxes;
- внутренняя экономика с монетами и dust;
- косметика: nameplates, avatar frames, badges, banners;
- система прогресса и наград.

### 6. Персонализация и интерфейс

- light/dark/custom themes;
- custom CSS;
- кастомный фон чата;
- 6 языков интерфейса.

### 7. Десктопная часть и инфраструктура

- нативное десктопное приложение на Tauri;
- installer/auto-update;
- single-instance запуск;
- системный tray;
- push notifications;
- storage для вложений;
- поддержка TURN/STUN для сетевой совместимости при screen share/video.

---

## Что пока находится в разработке / будет реализовано

Ниже — ключевой roadmap, который уже отражён в репозитории.

### b.ai.t — следующий уровень

Планируется усилить AI до полноценного “бота-ассистента” с большим набором действий:

- streaming responses в реальном времени;
- smarter routing моделей;
- улучшенное распознавание языка;
- больше инструментов для работы с сообщениями и каналами;
- управление темами, поиском, удалением сообщений и т.д.

### Бот в voice

Одна из самых интересных будущих фич — AI-бот, который будет:

- заходить в голосовой канал как виртуальный пользователь;
- воспроизводить музыку;
- слушать голосовые команды;
- выполнять действия через voice-интерфейс;
- стать “ботом для аудио/музыки/развлечений”.

### Музыка и мультимедиа

Планируется:

- воспроизведение аудио из ссылок и запросов;
- очередь треков;
- skip/pause/resume/stop;
- soundboard;
- интеграция с YouTube/SoundCloud/Spotify-источниками.

### Расширенный AI-скриптинг и сценарии

В планах:

- summarization thread-ов;
- LFG (party finder);
- in-voice trivia;
- proactive suggestions по контексту;
- multi-step server bootstrap через один запрос.

### Укрепление платформы

Также планируется:

- улучшение стабильности и надёжности;
- больше автоматизации в модерации;
- расширение кастомизации;
- развитие инфраструктуры для более крупных сообществ.

## Архитектура проекта

Проект состоит из нескольких слоёв:

### 1. Desktop client

- frontend: React + TypeScript;
- UI: Tailwind CSS;
- state management: Zustand;
- сборка: Vite;
- оболочка: Tauri 2.

### 2. Native layer

- Rust-powered audio/voice engine;
- обработка захвата экрана, аудио, системных операций;
- нативный доступ к низкоуровневым функциям.

### 3. Backend / cloud services

- Supabase как основная backend-платформа;
- Auth;
- Realtime;
- PostgreSQL;
- RLS policies;
- Storage;
- Edge Functions.

### 4. Media transport

- аудио через Supabase Realtime;
- видео/экран через WebRTC;
- TURN/STUN для работы сквозь NAT/firewalls.

### 5. Installer / distribution

- Tauri installer;
- auto-update;
- GitHub Releases.
